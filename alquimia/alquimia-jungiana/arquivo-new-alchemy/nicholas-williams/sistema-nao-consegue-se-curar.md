<h1 align="center">✧ O sistema não consegue curar a si mesmo ✧</h1>

O paradoxo é que o sistema jamais pode curar a si mesmo, pois o próprio sistema é a doença da qual ele deseja se curar. Eu tento resolver o problema, mas o problema sou eu – o problema sou eu tentando resolver o problema.

O que é o sistema? Se algo faz sentido para você, então isso é o sistema. Se algo faz sentido para mim, então isso é o sistema. O sistema é o criador da realidade, aquele que decide "o que é verdade". O sistema é o "controlador de significados". Se algo faz sentido para o sistema, então isso se torna real, torna-se verdade. Se algo não faz sentido para o sistema, então não se torna real, não se torna verdade.

O sistema é assustador quando conseguimos enxergá-lo. Ele determina o que podemos ver, determina o que podemos saber e, além disso, determina o fato de que não conseguimos perceber como ele determina o que podemos ver e saber. O sistema é assustador porque é invisível para si mesmo; ele acredita ser a realidade verdadeira, e não algo inventado. É assustador porque deseja nos transformar nele mesmo. Ele quer nos engolir, nos dominar, para que passemos a acreditar que ele é a realidade verdadeira.

Quando o sistema nos domina, de modo que nós somos o sistema e o sistema somos nós, tudo o que vemos faz perfeito sentido para nós. Faz um sentido tão perfeito que jamais duvidamos, nem por um instante; e, no entanto, tudo não passa de uma mentira. O sistema é o juiz da realidade, o padrão final e inquestionável que aplicamos a tudo, e, no entanto, ele próprio não é real. O sistema só é real para si mesmo; ele só faz sentido dentro de seus próprios termos. Ele só é real se concordarmos em fingir que é real e, depois, concordarmos em esquecer que fingimos. Essa é a realidade da mentira, que só pode se sustentar se continuarmos a apoiá-la, só se continuarmos a dizer que ela se sustenta por si só.

O sistema jamais pode ser feliz; ele só consegue fingir que é feliz e, depois, fingir que não está fingindo. Às vezes, porém, ficamos tão cansados que não conseguimos mais fingir que não estamos fingindo, e então percebemos que estamos tristes. Olhamos ao redor e vemos que todos os outros parecem ser felizes. Achamos que somos os únicos a estar tristes. As pessoas não gostam de ver nossa tristeza, pois ela ameaça lembrá-las de que elas também estão tristes; por isso, tentam nos "consertar" para que voltemos a ser "felizes". Se permanecemos tristes, dizem que estamos "deprimidos" ou "doentes mentais", e nos dão substâncias químicas para tentar bloquear essa tristeza. Nós também fazemos o possível para bloquear a tristeza, para fingir que ela não está ali. A isso chamamos de "terapia".

A terapia não é real, é apenas um teatro no qual todos fingimos acreditar e depois fingimos que não estamos fingindo. O sistema jamais pode curar a si mesmo, pois ele próprio é a doença.
